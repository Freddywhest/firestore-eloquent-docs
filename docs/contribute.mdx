# Contribute

:::info[IMPORTANT]
Check the current [roadmap](./todo.mdx) and open an issue before beginning a large API change.
:::

## How to contribute

- Check the [roadmap](./todo.mdx) and existing GitHub issues.
- Fork and clone the package repository.
- Create a focused branch for one fix or feature.
- Add or update PHPUnit coverage.
- Run `composer test`, `composer validate`, and PHP syntax checks.
- For Firestore behavior, test against the emulator; describe any live-project verification separately.
- Update these docs when an API, configuration key, return type, performance characteristic, or supported version changes.
- Open a pull request with the problem, approach, compatibility impact, and verification results.

Feel free to contribute by opening issues or submitting pull requests. Your feedback and contributions are highly appreciated :heart: :heart: :heart:
