# Create documents

Add writable fields to the model's `$fillable` property, then call `create()`:

```php
class User extends FModel
{
    protected $collection = 'users';
    protected $fillable = ['id', 'name', 'email', 'created_at'];
    protected $required = ['name', 'email'];
    protected $default = ['created_at' => null];
    protected $fieldTypes = ['created_at' => 'timestamp'];
}

$data = User::create([
    'name' => 'John',
    'email' => 'john@example.com',
    'created_at' => now(),
]);

echo $data['id'];
```

`create()` returns the stored field array, not a model result object. The package generates the primary key when it is absent. If a supplied primary key is not fillable, it is ignored and a new key is generated.

Defaults apply only to missing fillable fields. Required fields are checked on creation, and declared field types are validated before the request is sent.
