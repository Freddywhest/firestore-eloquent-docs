# Deleting documents

Retrieve a document result, then call `delete()`:

```php
$user = User::findOrFail('user-123');
$result = $user->delete();
```

Or retrieve it with a query:

```php
$user = User::where(['email', 'person@example.com'])->firstOrFail();
$user->delete();
```

The package does not cascade deletes to subcollections or related collections. Delete dependent documents explicitly when your data model requires it.
