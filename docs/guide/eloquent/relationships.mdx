# Relationships

Define `fHasOne`, `fHasMany`, and `fBelongsTo` methods directly on an `FModel`. Version 4.0 includes the relationship methods automatically; do not import `FRelations` into each model.

```php
class User extends FModel
{
    public function posts()
    {
        return $this->fHasMany(Post::class);
    }
}

class Post extends FModel
{
    public function author()
    {
        return $this->fBelongsTo(User::class, 'id', 'user_id');
    }
}

$posts = Post::with('author')->get();
```

See the complete [Relationships guide](../relationships.mdx) for default keys, custom keys, lazy loading, batched eager loading, nesting, and constraints.
