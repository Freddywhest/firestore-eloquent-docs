# Model configuration

```php
namespace App\FModels;

use Roddy\FirestoreEloquent\Facade\FModel;

class User extends FModel
{
    protected $collection = 'users';
    protected $primaryKey = 'id';
    protected $fillable = ['id', 'name', 'email', 'age', 'created_at'];
    protected $required = ['name', 'email'];
    protected $default = ['age' => 18];
    protected $fieldTypes = [
        'age' => 'integer',
        'created_at' => 'timestamp',
    ];
    protected $hidden = ['password', 'remember_token'];
}
```

## `$collection`

Sets the Firestore collection path. Define it explicitly to avoid depending on the class-name fallback.

## `$primaryKey`

Names the field that also identifies the Firestore document. It defaults to `id`. The generator's `--primaryKey` option changes it.

## `$fillable`

Lists fields accepted by `create()`, result-object `update()`, and `updateMany()`. An empty list prevents creation and updates.

Include the primary key only when callers may choose a document ID during creation. Result-object `update()` never changes the primary key.

## `$required`

Lists fields that must have non-null, non-blank values during `create()`. Partial updates do not require every creation field again.

## `$default`

Supplies missing fillable values during creation. Defaults may be values or Laravel `value()`-compatible callables.

```php
protected $default = [
    'created_at' => fn () => now(),
];
```

## `$fieldTypes`

Validates values and determines their Firestore encoding. Supported names are:

- `int`, `integer`
- `float`, `double`
- `numeric`, `number`
- `string`
- `bool`, `boolean`
- `array`, `list`
- `object`, `map`
- `date`, `datetime`, `timestamp`
- `null`

Date-looking strings stay strings unless the field is explicitly typed as a date/timestamp.

## `$hidden`

Excludes fields from `toArray()` and serialized output. It does not prevent direct property access and is not an authorization boundary.
