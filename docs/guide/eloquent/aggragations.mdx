# Aggregations

Version 4.0 uses Firestore server aggregation queries for counts, sums, and averages:

```php
$totalUsers = User::count();
$totalAge = User::sum('age');
$averageAge = User::avg('age');
```

Apply a supported query condition before the aggregate:

```php
$activeUsers = User::where(['status', 'active'])->count();
$activeBalance = User::where(['status', 'active'])->sum('balance');
```

The aggregate runs on Firestore; it does not download all matching documents into PHP. Firestore index requirements still apply.
