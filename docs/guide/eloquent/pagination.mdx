# Pagination

Version 4.0 supports three Laravel-compatible paginator types:

```php
User::orderByDesc('created_at')->cursorPaginate(20);
User::orderByDesc('created_at')->simplePaginate(20);
User::orderByDesc('created_at')->paginate(20);
```

Use cursor pagination for large collections. Use numbered pagination only when the interface needs page numbers and an exact total.

See [Pagination and large result sets](../pagination.mdx) for return types, JSON metadata, Livewire, performance tradeoffs, `chunk()`, and `lazy()`.
