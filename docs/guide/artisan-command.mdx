# Artisan Command

Generate a Firestore model with:

```bash
php artisan make:fmodel User
```

With the default configuration, this creates `app/FModels/User.php` in the `App\FModels` namespace.

:::info[Custom namespace]
The generator uses `class_namespace` from `config/firebase.php`. See [Configuration](../get-started/configuration.mdx#model-namespace).
:::

## Options

| Option | Short form | Description |
| --- | --- | --- |
| `--collection=` | `-c` | Firestore collection name |
| `--primaryKey=` | `-p` | Model primary-key field |
| `--force` | `-f` | Replace an existing generated model |

## Artisan Command Examples

### Generate a new model

```bash
php artisan make:fmodel User
```

```bash
php artisan make:fmodel User --collection=users
```

```bash
php artisan make:fmodel User --primaryKey=uid
```

```bash
php artisan make:fmodel User --collection=users --primaryKey=uid
```

The generated model contains `$collection`, `$primaryKey`, `$fillable`, `$required`, `$default`, and `$fieldTypes`. Add writable fields to `$fillable` before calling `create()` or `update()`.

```php
protected $fillable = ['uid', 'email', 'name'];
protected $required = ['email'];
protected $fieldTypes = ['email' => 'string'];
```
