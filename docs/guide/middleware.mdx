# Middleware

When `config/auth.php` uses the Firestore provider, prefer Laravel's built-in middleware:

```php
Route::middleware('auth')->get('/profile', ProfileController::class);
Route::middleware('guest')->get('/login', LoginController::class);
```

These use Laravel's configured guard, including the Firestore provider documented in [Authentication](./authentication.mdx).

## Legacy middleware

The package still registers `f.auth` and `f.guest` for applications using `FAuth`:

```php
Route::middleware('f.auth')->get('/profile', ProfileController::class);
Route::middleware('f.guest')->get('/login', LoginController::class);
```

`f.auth` redirects unauthenticated visitors to the named `auth_url` route. `f.guest` redirects authenticated visitors to the named `guest_url` route. Configure both in `config/firebase.php`.
