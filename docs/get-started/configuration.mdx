# Configuration

The published settings live in `config/firebase.php`.

```bash
php artisan vendor:publish --provider="Roddy\FirestoreEloquent\Providers\FModelProvider" --force
```

## Environment reference

| Variable | Default | Purpose |
| --- | --- | --- |
| `FIREBASE_PROJECT_ID` | none | Required Firestore project ID |
| `FIREBASE_DATABASE_ID` | `(default)` | Firestore database ID |
| `FIREBASE_CREDENTIALS` | none | Service-account JSON path |
| `GOOGLE_APPLICATION_CREDENTIALS` | none | Fallback credentials path used by Google tooling |
| `FIREBASE_PROJECT` | `app` | Key under `firebase.projects` |
| `FIRESTORE_EMULATOR_HOST` | none | Emulator host, such as `127.0.0.1:8080` |
| `FIREBASE_ALLOW_UNAUTHENTICATED` | `false` | Permit intentional public-rule production access |
| `GOOGLE_CLOUD_STORAGE_BUCKET` | none | Bucket used by file uploads |
| `FIREBASE_UPLOAD_MAX_SIZE` | `10485760` | Maximum upload size in bytes |

## Multiple projects

`firebase.default` selects a project from `firebase.projects`. Add another project configuration when an application needs it:

```php
// config/firebase.php
'default' => env('FIREBASE_PROJECT', 'app'),

'projects' => [
    'app' => [
        'credentials' => env('FIREBASE_CREDENTIALS'),
        'database' => [
            'project_id' => env('FIREBASE_PROJECT_ID'),
            'database_id' => env('FIREBASE_DATABASE_ID', '(default)'),
        ],
    ],
],
```

## Model namespace

`class_namespace` controls where `make:fmodel` creates models and how short relationship names are resolved.

```php
'class_namespace' => 'App\\FModels',
```

The default creates models in `app/FModels`. You may use a fully qualified class name in relationships regardless of this setting.

## Authentication settings

The legacy `FAuth` helper uses `auth_model`. The native Laravel provider reads its model from `config/auth.php` and falls back to this value.

```php
'auth_model' => App\FModels\User::class,

'auth' => [
    'password_field' => 'password',
    'remember_token_field' => 'remember_token',
],
```

`guest_url` and `auth_url` are named routes used by the package's legacy `f.guest` and `f.auth` middleware.

## Upload restrictions

The maximum size is measured in bytes. An empty MIME-type list allows all detected types; define an allow-list for user uploads:

```php
'upload' => [
    'max_size' => env('FIREBASE_UPLOAD_MAX_SIZE', 10 * 1024 * 1024),
    'allowed_mime_types' => [
        'image/jpeg',
        'image/png',
        'application/pdf',
    ],
],
```

The package generates a UUID-based object name and sanitizes the destination path, but your application should still validate the upload before calling the storage method.
